# 異種孵化場 Xeno Hatchery

原創數碼獸養成網頁遊戲原型（v0.3，怪獸動畫與測試工具見 CHANGES_v0.3.md；介面改版見 CHANGES_v0.2.md）。核心玩法：快速養成 → 圖鑑收集 → 放生換素材。

## 執行
直接用瀏覽器打開 `src/index.html` 即可遊玩（純 HTML/JS，存檔在 localStorage）。
`./build.sh` 會把 `src/` 複製成 `dist/` 作為發佈版本。

## 內容
- `src/`：遊戲程式（繁體中文介面，含 DEV 面板、22 隻圖鑑、放生、每日任務、機率公開頁）
- `src/img/`：遊戲用角色與蛋的圖
- `art/`：爬蟲系 22 隻定稿美術 v7.4（R-001～R-022 透明圖、8 條進化路線圖、總覽樹、調色盤 palette_v7）

## 進化階段
蛋 → 初胚體 → 幼化體 → 成形體（開始分支）→ 覺醒體 → 極限體
